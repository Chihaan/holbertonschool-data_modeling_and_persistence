# SQL - Join

## Description
Requêtes SQL utilisant des jointures entre plusieurs tables et des fonctions d'agrégation (moyennes, comptages).

## Fichiers

| Fichier | Description |
|---|---|
| `1-books-with-authors.sql` à `15-instructors-with-active-courses.sql` | Requêtes de jointures et agrégations sur les bases `library.db` et `academy.db` |
| `academy.db` / `library.db` | Bases de données SQLite utilisées pour les requêtes |
